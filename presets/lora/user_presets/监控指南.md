```
收敛：0.05-0.15

异常信号：
- 持续上升 → 学习率太高
- 不下降 → 学习率太低
```


## 🚨 异常情况处理

### Loss异常
| 现象 | 原因 | 解决方案 |
|------|------|----------|
| Loss上升 | 学习率过高 | 降低learning_rate到0.00005 |
| Loss不降 | 学习率过低 | 提高learning_rate到0.0002 |
| Loss震荡 | 批次太小 | 增加train_batch_size |

### 显存异常
| 现象 | 解决方案 |
|------|----------|
| OOM错误 | 降低train_batch_size到4 |
| 显存不足 | 启用gradient_checkpointing |
| 显存空闲 | 增加train_batch_size到8 |

## 🖼️ 采样图片监控

### 质量评估时间点
- **500步**: 检查是否有初步风格
- **1000步**: 风格应该开始明显
- **2000步**: 质量达到可用水平
- **4000步**: 通常最佳效果点
- **6000步+**: 检查过拟合

### 过拟合识别
- 采样图片过于相似
- 细节丢失，变得模糊
- 只能生成训练集相似内容

## 📊 最佳实践

### 监控频率
- **Loss值**: 每50-100步检查
- **采样图片**: 每500步评估
- **显存状态**: 每10分钟检查
- **整体进度**: 每1000步总结

### 干预时机
- **1000步前**: 主要看Loss下降趋势
- **1000-3000步**: 平衡Loss和采样质量
- **3000步后**: 重点防止过拟合
- **Loss连续50步不降**: 考虑调整参数

### 保存策略
- **每500步保存**: 便于选择最佳模型
- **记录每个检查点的采样质量**
- **保留Loss最低的几个模型**

## 🎯 目标指标

### 优秀训练的标志
✅ Loss平滑下降到0.05-0.1  
✅ 采样图片风格一致且清晰  
✅ 显存使用稳定  
✅ 训练速度保持恒定
